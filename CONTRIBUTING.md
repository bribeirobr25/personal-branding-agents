# Contributing

Contributions to reusable methodology, role design, templates and synthetic examples are welcome.

Before proposing a change:
1. Read [security and privacy](docs/security-and-privacy.md).
2. Confirm you have rights to share the material.
3. Use only **synthetic** profiles and examples.
4. Explain which workflow or quality gate the change improves.
5. Add a minimal example or test case when possible.
6. Prefer small, reviewable changes over broad rewrites.

Do **not** upload real resumes, client data, secret keys, internal workplace documents, unpublished posts or sensitive screenshots into issues, pull requests or commits. Public pull requests are public.
