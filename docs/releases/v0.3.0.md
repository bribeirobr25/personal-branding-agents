# Method 0.3.0 release candidate

Discovery B updates the Orchestrator, Researcher and onboarding workflow. It keeps the conversation concise while tracking source permissions, evidence and corrections.

- Ask for explicit confirmation of a bounded profile before strategic positioning. Leave unresolved claims out of decisions that depend on them.
- Check permission before each source access. Record what was authorized, retrieved, extracted and verified.
- Revisit only claims affected by a correction. Offer one useful provisional step when time or evidence is limited.

The public checkout contains the reusable framework, usage guides and fictional examples. Its CI checks documentation, contracts and templates. Evaluation suites and internal review records are maintained in the private laboratory.

## Adopt or roll back

Method 0.3.0 retains the 0.2.0 record contracts and templates. The Discovery checkpoint is local to onboarding. Continue using the existing shared lifecycle and approval records.

After publication, pin the release tag and full commit SHA in your private workspace. Review the three updated prompts against local overrides and verify consent withdrawal, corrections and validation before adopting them. Roll back by restoring the prior pin and compatible overrides. For older records, see [migration to 0.2.0](v0.2.0.md).
